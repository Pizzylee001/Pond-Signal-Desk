1. Load the ICP, offer, approved proof points, exclusion list, and every existing lead from the Leads tab for dedupe.
2. Search X (public reads) and LinkedIn (my signed-in browser, content search sorted by Latest) for posts in the lookback window (72h on Mondays, 36h otherwise) using the keyword list in the skill.

4. Dedupe, qualify, and score every candidate with the rubric in the skill. Quote the evidence for each score.

6. Run the self-check on each draft. Rewrite any draft that fails.
7. Append today's scored leads to Leads and one summary row to Runs.
8. Post the daily digest here and wait for my approval.
